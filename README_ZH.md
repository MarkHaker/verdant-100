### 触控屏与鼠标操作
- **模压十字键 (D-Pad)**: 直接点击 4 个方向箭头，或在十字键圆形感应区内直接滑动控制。
- **START 与 SORT BY CATEGORY 胶囊键**: 屏幕正下方的倾斜实体按键，带立体按压反馈。
- **A 与 B 动作按键**: 右侧经典的双色圆形按键，点击即可触发对应动作。
- **POWER 电源开关**: 右上角的大号复古电源拨动开关，带工作状态彩色 LED 指示灯。
- **底部辅助功能坞**: 支持静音开关 (`MUTE`)、扫描线滤镜 (`CRT`)、全屏自适应 (`FULLSCREEN`) 和系统菜单 (`MENU`)。

## ⚡ 系统核心亮点

- **开局速度与难度调节**:
  - 针对需要即时反应的街机类游戏，卡带预览页面提供专属难度切换：
    - **EASY (0.75x)** — 降速模式，节奏舒适悠闲。
    - **NORMAL (1.00x)** — 官方标准基准速度。
    - **HARD (1.40x)** — 超速硬核挑战，极度考验反应力。
  - 回合制逻辑解谜游戏（如 2048、推箱子、国际象棋、数独）已自动锁定时间限制，无需担心倒计时惩罚。
- **实时 Web Audio 芯片音乐合成引擎 (APU)**:
  - 100% 游戏音效与背景音乐均为浏览器振荡器（方波、三角波、正弦波、白噪声）经低通滤波器实时合成。没有加载任何体积庞大的外部 MP3/WAV 音频文件。
  - 内置舒缓优美的 Lo-Fi 氛围和弦曲（Cmaj9 → Am9 → Fmaj7 → G6）与温和轻柔的按键触感音。
- **P1 绿色荧光管 CRT 显示管线**:
  - 256x240 点对点原生画布像素渲染，搭配逼真的水平阴极扫描线、边缘暗角渐变以及开关机显像管光束收缩动画。
- **全平台零依赖**:
  - 零 npm 依赖，零外部框架，零编译构建步骤。双击打开 `index.html` 或托管在任意静态网站空间即可运行。

## 🚀 快速启动

### 方式 1：即开即玩 (无需任何配置)
1. 下载或克隆此代码仓库。
2. 在任意现代浏览器（Chrome、Edge、Safari、Firefox）中双击打开 `index.html` 即可启动。

### 方式 2：本地小型静态服务器
```bash
# 使用 Node.js (npx)
npx serve .

# 或使用 Python
python -m http.server 8080
```
随后在浏览器输入 `http://localhost:8080` 即可游玩。

## 🌐 部署至 GitHub Pages

1. 将本仓库 Fork 或推送至您的 **GitHub** 账户。
2. 在 GitHub 仓库页面点击 **Settings** $\to$ **Pages**。
3. 在 **Build and deployment** 区域：
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` 分支，目录选 `/ (root)`
4. 点击 **Save** 保存。约 1 分钟后，掌机网页即可在线访问：
   `https://<你的GitHub用户名>.github.io/verdant-100/`
